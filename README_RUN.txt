EXAM MANAGEMENT SYSTEM - RUN INSTRUCTIONS

1. Open Terminal.
2. Go to the project folder:
   cd ~/Downloads/exam-management-git-ai-project-final

3. Install dependencies:
   npm install

4. Run the project:
   npm run dev

5. Open the local URL shown in Terminal, usually:
   http://localhost:5173
