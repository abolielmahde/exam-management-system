Main Entities
=============

1. User
-------
Fields:
- id
- fullName
- email
- passwordHash
- role: teacher or student
- createdAt

Purpose:
Represents a system user. Teachers create exams and review submissions. Students submit exams and view results.

2. Exam
-------
Fields:
- id
- teacherId
- title
- course
- description
- durationMinutes
- status: draft, published, closed
- questions JSONB
- createdAt
- updatedAt

Purpose:
Represents an exam created by a teacher. Questions are stored as flexible JSONB objects so the system can support multiple question types.

3. Question
-----------
Fields:
- type: multiple-choice, true-false, open-text
- text
- options
- correctAnswer
- points

Purpose:
Represents one question inside an exam.

4. Submission
-------------
Fields:
- id
- examId
- studentId
- answers JSONB
- grade
- feedback
- isPublished
- submittedAt
- updatedAt

Purpose:
Represents a student's answers and grade for a specific exam.
