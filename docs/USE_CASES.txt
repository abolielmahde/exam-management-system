USE CASES

USE CASE 1 - Teacher Login
Actor: Teacher
Flow:
1. Teacher opens Login page.
2. Teacher enters email and password.
3. AuthService validates credentials using MockApiDbService.
4. Teacher is redirected to Teacher Dashboard.

USE CASE 2 - Student Login
Actor: Student
Flow:
1. Student opens Login page.
2. Student enters email and password.
3. AuthService validates credentials.
4. Student is redirected to Student Dashboard.

USE CASE 3 - Register New User
Actor: Guest
Flow:
1. User opens Register page.
2. User enters full name, email, password, confirmation password, and role.
3. The form validates password length and confirmation.
4. AuthService creates the user.
5. User is logged in automatically.

USE CASE 4 - Teacher Creates Exam
Actor: Teacher
Flow:
1. Teacher opens Create Exam page.
2. Teacher enters title, course, description, questions, answers, and correct answers.
3. MockApiDbService saves the exam as draft.
4. Teacher is redirected to My Exams.

USE CASE 5 - Teacher Publishes Exam
Actor: Teacher
Flow:
1. Teacher opens My Exams.
2. Teacher clicks Publish.
3. MockApiDbService changes status from draft to published.
4. Students can now see the exam.

USE CASE 6 - Teacher Closes Exam
Actor: Teacher
Flow:
1. Teacher opens My Exams.
2. Teacher clicks Close.
3. MockApiDbService changes status to closed.
4. Students can no longer see it as open.

USE CASE 7 - Student Submits Exam
Actor: Student
Flow:
1. Student opens Student Dashboard.
2. Student selects a published exam.
3. Student answers all questions.
4. Student clicks Submit Exam.
5. MockApiDbService calculates grade and saves submission.

USE CASE 8 - Student Views Results
Actor: Student
Flow:
1. Student opens Results page.
2. System loads all submissions for that student.
3. Student sees exam title, submission time, and grade.

USE CASE 9 - Teacher Reviews Submissions
Actor: Teacher
Flow:
1. Teacher opens Submissions page.
2. System loads submissions related to the teacher's exams.
3. Teacher sees student name, exam name, submission time, and grade.
