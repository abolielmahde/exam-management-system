Use Cases
=========

Use Case 1 - Register/Login
---------------------------
Actor: Teacher or Student.
Flow:
1. User enters email and password.
2. Frontend sends request to backend.
3. Backend validates credentials.
4. Backend returns JWT token.
5. Frontend stores token and redirects user by role.

Use Case 2 - Teacher Creates Exam
---------------------------------
Actor: Teacher.
Flow:
1. Teacher opens Create Exam page.
2. Teacher fills title, course, description and time limit.
3. Teacher adds questions and selects question type.
4. Frontend sends exam data to backend.
5. Backend validates data and saves exam in PostgreSQL as draft.

Use Case 3 - Teacher Publishes Exam
-----------------------------------
Actor: Teacher.
Flow:
1. Teacher opens My Exams page.
2. Teacher clicks Publish.
3. Backend updates exam status to published.
4. Students can now see the exam.

Use Case 4 - Student Submits Exam
---------------------------------
Actor: Student.
Flow:
1. Student opens Student Dashboard.
2. Student starts a published exam.
3. Timer starts.
4. Student answers all questions.
5. Frontend sends answers to backend.
6. Backend saves submission and calculates automatic grade.

Use Case 5 - Teacher Reviews Submissions
----------------------------------------
Actor: Teacher.
Flow:
1. Teacher opens Student Submissions.
2. Teacher sees all submissions for his exams.
3. Teacher can change grade, add feedback and choose publish status.
4. Backend updates submission.

Use Case 6 - Student Views Results
----------------------------------
Actor: Student.
Flow:
1. Student opens Results page.
2. Backend returns the student's published submissions.
3. Student sees grade, feedback and personal average graph.

Use Case 7 - Teacher Analytics
------------------------------
Actor: Teacher.
Flow:
1. Teacher opens dashboard or submissions page.
2. Frontend calls analytics endpoint.
3. Backend calculates class average, highest grade, lowest grade and active students from PostgreSQL.
4. Frontend displays cards and graph.
