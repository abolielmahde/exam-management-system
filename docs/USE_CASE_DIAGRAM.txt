Time Limit Feature:
Teachers set a duration in minutes when creating an exam. Students see the time limit before starting and during the exam. When the timer reaches zero, the exam is submitted automatically.

Student Average Feature:
The teacher can view the class average and compare every submission to the average. The student can view a personal average based on submitted exams.
