טקסט קצר להצגה מול המרצה
=========================

הפרויקט שלנו הוא מערכת Full Stack לניהול מבחנים אונליין. המערכת בנויה מ־Frontend ב־React, Backend ב־Node.js ו־Express, ובסיס נתונים PostgreSQL. יש במערכת שני סוגי משתמשים: מרצה וסטודנט. המרצה יכול להתחבר, ליצור מבחן, להוסיף שאלות מסוגים שונים, לפרסם את המבחן, לסגור אותו, לראות הגשות של סטודנטים, לעדכן ציונים, להוסיף משוב ולפרסם תוצאות. הסטודנט יכול להתחבר, לראות מבחנים זמינים, להיכנס למבחן עם טיימר, להגיש תשובות ולראות ציון, משוב וממוצע אישי.

בצד האבטחה השתמשנו ב־JWT Authentication. אחרי התחברות השרת מחזיר Token, וכל בקשה מוגנת נשלחת עם Authorization Header. בנוסף יש Role-Based Authorization, לכן סטודנט לא יכול לבצע פעולות של מרצה. הסיסמאות נשמרות בשרת כ־bcrypt hash ולא כטקסט רגיל.

בצד בסיס הנתונים יש שלוש טבלאות מרכזיות: users, exams, submissions. בתוך exams שמרנו את השאלות כ־JSONB כדי לתמוך בכמה סוגי שאלות בלי לשנות את מבנה הטבלה בכל פעם. בתוך submissions שמרנו את התשובות גם כ־JSONB. המערכת עושה בדיקות תקינות לפני שמירה, כמו תקינות אימייל, סיסמה, סטטוס מבחן, סוגי שאלות וטווח ציון.

מבחינת DevOps הוספנו Docker Compose שמפעיל יחד Frontend, Backend ו־PostgreSQL. בנוסף הוספנו GitHub Actions שמבצע build ל־Frontend, מריץ בדיקות Backend ועושה npm audit לבדיקת חולשות. לכן הפרויקט מדגים לא רק מערכת עובדת, אלא גם ארכיטקטורה, אבטחה, בסיס נתונים, תקשורת Frontend/Backend ותהליך פיתוח מסודר.
