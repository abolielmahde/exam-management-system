Responsibilities:
App:
- Controls current page state.
- Controls current user state.
- Initializes MockApiDbService.

NavigationMenu:
- Shows navigation according to user role.
- Handles logout.

Toast:
- Shows user notifications.

Auth Pages:
- Login and registration.

Teacher Pages:
- Dashboard statistics.
- Exam creation.
- Exam status management.
- Submission review.

Student Pages:
- Published exam list.
- Exam answering.
- Result display.
