React Component Hierarchy
=========================

App
├── NavigationMenu
├── Toast
├── Login
├── Register
├── TeacherDashboard
├── CreateExam
├── TeacherExams
├── TeacherSubmissions
├── StudentDashboard
├── TakeExam
└── StudentResults

Service Layer
-------------
AuthService
- login
- register
- logout
- currentUser

ApiService
- calls backend REST API using fetch
- stores JWT token
- sends Authorization header
- exams API methods
- submissions API methods
- analytics API method

StorageService
- stores only current user and token in browser localStorage

Backend Modules
---------------
server.js
├── authRoutes
├── examRoutes
├── submissionRoutes
├── analyticsRoutes
├── auth middleware
├── role middleware
└── PostgreSQL pool/initDatabase
