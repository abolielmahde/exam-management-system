Exam Management System - Full Stack Context
==========================================

This project is a full stack online exam management system.
Frontend: React + Vite.
Backend: Node.js + Express.
Database: PostgreSQL with JSONB for exam questions and answers.
Authentication: JWT + bcrypt.
DevOps: Docker Compose and GitHub Actions.

Main frontend services: AuthService, ApiService, StorageService, LoggerService, NotifyService, ConfigurationService.
Main backend modules: authRoutes, examRoutes, submissionRoutes, analyticsRoutes, requireAuth middleware, requireRole middleware, PostgreSQL pool and initDatabase.
